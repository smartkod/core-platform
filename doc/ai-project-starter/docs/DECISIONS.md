## Rules

1. Do not silently replace an accepted decision.
2. If a new requirement conflicts with an accepted decision, propose a new ADR.
3. Prefer reversible decisions when requirements are uncertain.
4. Record why an important option was rejected.
5. Do not create an ADR for trivial implementation details.
